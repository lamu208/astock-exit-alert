加仓与离场纪律

核心原则趋势优先 → 量价确认 → 回踩优先 → 分批建仓 → 上涨加仓 → 破位减仓

一、入场四模式

  1. 趋势突破突破 20 日新高 + 放量（1.3～1.8 倍）+ MA5 ＞ MA10 ＞ MA20。
  2. 回踩确认缩量回踩 MA10 / MA20，出现锤子线或吞没形态，并重新转强。
  3. 反转形态早晨星 + 反弹突破前高 + 成交量改善。
  4. 超跌反弹股价超跌 + 下跌衰减 + 板块企稳，仅用于不超过 20% 的小仓位。

二、金字塔加仓

  1. 第 1 档（30%～40%）初始突破建立底仓。
  2. 第 2 档（20%～30%）缩量回踩支撑 + 止跌确认。
  3. 第 3 档（10%～20%）放量突破前高 + 多头排列保持。

禁止追高：连续 3 根大阳线、股价距离 MA20 超过 10%～12%、放巨量长上影线、个股涨但板块弱。

三、离场五层递进

  1. 动能减弱缩量跌破 MA5 → 仅作观察，不卖。
  2. 趋势转弱缩量跌破 MA10 → 暂不动作；放量跌破 MA10 → 进入观察。
  3. 趋势破坏放量跌破 MA20 → 减仓 30%～50%；缩量跌破 → 先观察。
  4. 结构破坏放量跌破前期突破平台或关键支撑 → 继续减仓。
  5. 趋势反转MA5 下穿并持续走弱，且量价确认 → 按纪律离场。

四、量价与 K 线决策顺序

上涨放量趋势确认，可加仓。

上涨缩量可持有，不追高。

下跌缩量正常回踩，观察支撑。

放量滞涨警惕高位换手，准备减仓。

放量长上影警惕资金兑现，执行减仓信号。

放量跌破趋势线优先立即减仓或清仓。

长上影 + 大阳线后 + 放量减仓 50%～60%。

对顶 + 放量减仓 60%～70%；极端长上影线立即清仓。

五、最终动作优先级

可加仓回踩确认优先；趋势突破、反转形态按档位执行。

可持有上涨缩量或下跌缩量，继续观察，不追高。

警示信号放量滞涨、跌破 MA10、长上影，先观察量价。

减仓信号放量长上影 → 减仓 50%～60%。

减仓 30%～50%放量跌破 MA20 或关键支撑。

不卖缩量破 MA5 / MA20，按纪律先观察。

止损放量破 MA5 且未收回 → 减仓 30%。

D档加仓破位后 2～3 根 K 线不创新低 → 反弹补仓。

出 60%～70%对子顶叠加放量。

立即清仓极端长上影，或放量跌破趋势线并叠加恶化形态。
